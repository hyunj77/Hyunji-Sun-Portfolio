# 이미지 넣는 방법

이 폴더(`images/`)에 아래 파일명 그대로 사진을 넣으면 사이트에 자동으로 표시됩니다.
파일이 없는 동안은 회색 placeholder 박스가 대신 보입니다.

| 위치 | 파일명 | 권장 크기 |
|---|---|---|
| Home 배경 사진 | `hero.jpg` | 1200x960 이상, 가로로 넓게 |
| About 프로필 사진 | `about.jpg` | 358x430 (세로) |
| Contact 사진 | `contact.jpg` | 800x375 (가로) |

Project(프로젝트 1~7)와 Design(웹디자인/그래픽 갤러리)은 아직 실제 작업물이 없어서
이미지 연결 없이 빈 자리만 만들어뒀습니다. 나중에 실제 프로젝트가 생기면
`css/style.css`의 `#portfolio`, `#design` 부분에 이미지 경로를 추가하면 됩니다.
